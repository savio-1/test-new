The 3D model opens in Blender, three.js and most 3D viewers. It includes the photo camera, so a render from that camera lines up with the original image.

Depth by Depth Anything V2 Small (Apache-2.0), run on-device with ONNX Runtime Web. One photo only shows one side of things, so hidden surfaces stay open. The result reads best within about 30° of the original view.
